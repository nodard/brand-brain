Brand Brain

A dated fact ledger for every AI tool a brand runs. Open models on Fireworks.
1 · The problem

Ten AI tools, one set of facts, all going stale

What a brand's tools need, right now

  • Live promo code
  • Free-shipping threshold
  • Hero product and its price and supplier
  • Target customer, ad cap, return window

What happens today

  • Each tool re-reads the whole Slack history, every question
  • Or it quotes a value that was replaced three weeks ago
  • Nobody can say when a fact took effect or what it replaced
2 · Tech stack

Extract once, verify once, answer from SQL

1 · ExtractNVIDIA Nemotron Lightning 3.5 on Fireworks reads the ops log in batches and pulls (entity, attribute, value). Dates come from the message timestamp, never the model.
2 · VerifyDeepSeek V4.1 Flash on Fireworks checks each source message: a decision, or a proposal, question, or someone recalling an old value?
3 · StoreSQLite with validity intervals. A new value closes the old row. current, as_of(date), full history, source id.
4 · AnswerOne small routing call, then SQL. Two-hop questions resolve the hero product in code. ~340 prompt tokens instead of 14,500.
