1. The problem

Show the top of the demo page.

A brand runs many AI tools. Ads, support, email.

They all need the same facts. The current promo code. The shipping threshold. The hero product.

Today each tool either reads the whole Slack history every time, or uses an old value.

2. Tech stack

Scroll to the four steps, then the terminal output.

Brand Brain is a memory of what the company decided, and when.

NVIDIA Nemotron on Fireworks reads the Slack log and pulls out decisions.

DeepSeek on Fireworks checks each one. Real decision, or just a proposal or an old value someone mentioned?

Each fact is stored with a start date, an end date, and the message it came from.

A question is one small model call plus a database lookup.

Fireworks made this cheap enough to check every message. Under a second, a fraction of a cent.

Here is the output. Promo code FALL30, since 17 October, from this message. It replaced VIP15.

3. Benchmark

Scroll to the table.

Baseline: Claude Opus 5.5 reads the full log with the same prompt.

120 test questions we could not tune on.

Opus: 100 percent.

DeepSeek reading the full log: 83.

Brand Brain on open models: 79.

At one 160th of the cost per correct answer. 43 times fewer tokens. 10 times faster.

It beats DeepSeek on two-step questions, 14 to 10.

Our first version scored 27. Adding the check step took it to 79. Memory is deciding what counts as a fact.

We do not beat Opus on accuracy. We say so. Everything reproduces with one command.
